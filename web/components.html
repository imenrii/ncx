ncx component approaches

Brutalist reading: plain grid boxes, hairline rules, square corners, no shadow and no radius. State is carried by texture — a 2 px checkerboard at 7 % ink for hover and 14 % for pressed — so every state survives greyscale and colour stays reserved for data. Type is Commit Mono inside controls (it lines up in a column and it never re-flows when a value changes) and Gorton Perfected for prose around them.

B — shared spine (recommended)

One outer hairline, 1px dividers · reads as one instrument
focus inset so the outline never breaks the spine

C — ledger rule

No box until hover · lightest over a plot
weakest affordance: only use where the target is obvious

Glyphs on a 10px grid, currentColor · 30×28 cells

B — amber state, dither touch

Timeline

A — ruled track

Axis, not a slider: baseline rule + 5px ticks + 2px head
value set in Commit Mono above the head, never centred in a bubble

B — sample cells

One cell per step · honest when steps are few
hover 7%, current 14% · degrades badly past ~60 steps
