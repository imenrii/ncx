# Speed Highlight for the Steering draft

Unmodified files from `@speed-highlight/core` 2.1.0, licensed under CC0-1.0.
Source: <https://github.com/speed-highlight/core>.
Package: <https://registry.npmjs.org/@speed-highlight/core/-/core-2.1.0.tgz>.

Only the entry point, Python grammar, and its TODO-comment grammar are included.
The draft uses `highlightHTML(code, 'py', {block: false})`; other languages are
not bundled. Serve the workspace over HTTP to load these local ES modules.
These files are prototype assets, not a production dependency.
