INSTRUCTIONS

Gorton Perfected is available in two flavors for desktop app use:
- variable font (one TTF file)
- non-variable font (7 OTF files)

Gorton Perfected is available in two flavors for web app use:
- variable font (one WOFF or WOFF2 file)
- non-variable font (7 WOFF or WOFF2 files)

To use the font on your computer, you most likely need to install GortonPerfectedVF.ttf in the “Font (variable)” folder, the way you normally install fonts.

For more information about variable font support, please refer to: https://v-fonts.com/support/

Terms for desktop and web use can be found in the accompanying license.
